PSR-12 rules left to implement
==============================

Reference: PHP-CS-Fixer @PSR12 = @PSR2 (+ @PSR1) plus extra rules.
Below: everything in that set NOT yet implemented in ecs-go, grouped by what
they need. Implemented rules (26) are listed at the bottom for reference.

Legend:
  [AST]   needs a real statement/AST model (brace/scope/type awareness) -
          not safe on the flat token stream. Adopt php-parser-in-go next.
  [TOKEN] doable on the current token stream in a future PR (bounded risk).
  [LEX]   blocked on a lexer gap (heredoc/nowdoc, casts as tokens, ...).


A small statement/scope layer now exists (Stream.MatchForward/MatchBackward +
classifyBrace, which labels each "{" as class-like / function / closure /
control / other). braces_position is implemented on it; the rules below become
reachable next by extending the same layer (member iteration, statement spans).

NEEDS AST / STATEMENT MODEL
---------------------------
class_definition                spacing in class/interface/trait headers
function_declaration            "function" signature spacing, closures
method_argument_space           multi-line argument layout, one-per-line
compact_nullable_type_declaration   "? int" -> "?int" in type positions
return_type_declaration         spacing around ":" of a return type
ternary_operator_spaces         spacing around ternary "?"/":" (: is ambiguous)
ordered_imports                 sort use statements
ordered_class_elements          reorder class members (use_trait first)
single_class_element_per_statement   split "public $a, $b;"
single_trait_insert_per_statement    split "use A, B;" inside a class body
visibility_required             add public/… to methods, properties, consts
modifier_keywords               modifier presence + ordering (casing done)
new_with_parentheses            "new Foo" -> "new Foo()" (needs class-name ctx)


NEEDS LEXER WORK
----------------
(heredoc / nowdoc are now lexed as opaque string tokens - fixers leave them
 alone. no_closing_tag and full_opening_tag are implemented.)
no_trailing_whitespace_in_comment   trim inside comment tokens


TOKEN-DOABLE NEXT (bounded)
---------------------------
